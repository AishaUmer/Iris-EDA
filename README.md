# Iris Dataset - Exploratory Data Analysis (EDA)

This repository contains a Python-based Exploratory Data Analysis (EDA) of the famous Iris dataset. Using fundamental data science libraries, this project explores the structural attributes of iris flowers to visually differentiate between three distinct species.

## 🚀 Project Overview

The objective of this project is to load, inspect, and visualize the Iris dataset to understand the relationships and distributions of flower traits (`sepal length`, `sepal width`, `petal length`, and `petal width`) across different species (*Setosa*, *Versicolor*, and *Virginica*).

## 🛠️ Tech Stack & Dependencies

* **Python 3.x**
* **Pandas**: For data loading and structural inspection.
* **Matplotlib**: For core visualization layouts.
* **Seaborn**: For advanced statistical plotting.
